# Security

This project is an instruction-only workspace template. It does not run
experiment code or talk to servers by itself.

**Do not** open issues or PRs that include:

- live `.research/` science, experiment IDs from a real project, or results
- credentials, cookies, tokens, webhook URLs, or private server paths
- dataset dumps

If you find a credential or private science overlay in a commit, rotate the
secret and tell the maintainer privately. Do not paste the secret into a
public issue.
